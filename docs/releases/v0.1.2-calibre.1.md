# RSVP Nano v0.1.2-calibre.1

A fix release on top of v0.1.2-calibre. Two books with the same name no longer
share, overwrite or delete each other's file on the card.

## Every book gets a file of its own

Calibre books are saved under their title. Until now that was the whole name, so
two books could end up writing to the same file:

- the same title by two authors ("Poems");
- titles that differ only in accents or capitals ("Ética" and "etica" are the same
  name on the card);
- long titles that only differ after the first 72 characters.

When that happened, the second download silently replaced the first. Worse, removing
one of them from Calibre (Mirror policy) deleted the file the other was still using.
A book retitled in Calibre could also delete another book's file when it was renamed
on the card.

Now one book keeps the plain name and the others get their Calibre id added:
`Poems.rsvp` and `Poems (12).rsvp`. The book already on your card keeps its name, so
adding a new book with the same title never renames the one you have. The sync also
no longer overwrites a book with the same name that came from somewhere else, such as
a companion app upload or an RSS article.

If two books were already sharing a file on your card, the next sync downloads both
again, each into its own file. The shared file is only removed once no book uses it.

## Upgrading

OTA from the device: Device → check for firmware update. Nothing changes for a library
without duplicate titles. The first sync after updating downloads nothing new and
renames nothing.
